# MyMonkeyApp

이슈 #1의 원숭이 콘솔 앱입니다. .NET 9 SDK가 필요합니다.

```bash
dotnet run --project workshop/MyMonkeyApp/MyMonkeyApp.csproj
```

저장소 루트에서 실행하세요. 메뉴에서 `1`은 전체 목록, `2`는 이름별 상세 조회, `3`은 무작위 선택, `4`는 종료입니다. 이름 검색은 대소문자와 앞뒤 공백을 무시합니다. 유효하지 않은 메뉴나 빈 이름, 없는 이름에는 안내 문구를 표시합니다. 입력 스트림이 끝나면 앱을 종료하며, 파이프 입력에서는 키 입력 대기를 생략합니다.

데이터는 `Program.cs`의 샘플 원숭이 세 마리로 제공됩니다. 외부 MCP 서버 호출이나 실시간 개체수 조회 기능은 포함하지 않습니다. `MonkeyHelper.LoadMonkeys`에 새 목록을 제공하면 데이터를 교체할 수 있습니다.
